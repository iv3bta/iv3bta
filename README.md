## 🎮 Echoes of the Lost Seas

A 2D platformer built from scratch in Java — no game engine, no framework.

<table>
<tr>
<td width="50%" valign="top">

**Engine**
- Tile-based map system
- Collision detection and physics
- Sprite animation and rendering
- Audio playback

</td>
<td width="50%" valign="top">

**Game**
- Enemy AI and combat
- Boss fight
- SQLite save system
- Full UML documentation
